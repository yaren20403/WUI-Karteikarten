Leertaste umdrehen · → gewusst · ← nochmal
So funktioniert der Lernstapel
  • Du lernst immer nur so viele Karten gleichzeitig, wie oben eingestellt (z. B. 10).
  • Eine Karte verlässt den Stapel erst, wenn du sie gewusst hast. Erst dann rückt eine neue Karte nach.
  • Hast du eine Karte einmal falsch gehabt, musst du sie zweimal hintereinander wissen.
  • Etwa jede 4. bis 5. Karte ist eine Wiederholung einer Karte, die du schon kannst. Weißt du sie nicht mehr, kommt sie zurück in den Stapel.
  • Je öfter du eine Karte bei Wiederholungen weißt, desto höher ihre Stufe (1–5) und desto seltener kommt sie dran.
